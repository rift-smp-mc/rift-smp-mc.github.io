# Rift SMP Website

Responsive landing page für Rift SMP mit dunklem Lila/Pink-Design und dem bereitgestellten Banner.

## Dateien
- `index.html` – Inhalte und Struktur
- `style.css` – Design und mobile Darstellung
- `script.js` – mobiles Navigationsmenü und dynamisches Jahr
- `assets/rift-smp-banner.png` – bereitgestelltes Rift-SMP-Bild

## Veröffentlichen
Lade den gesamten Inhalt dieses Ordners in das Root-Verzeichnis deines GitHub-Pages-Repositories hoch. Behalte dabei den Ordner `assets` samt Banner bei.

## Noch zu ergänzen
Server-IP, Port, Discord-Invite und konkrete Links zu weiteren gehosteten Projekten wurden nicht angegeben. Deshalb behauptet die Seite nicht, dass der Server gerade online ist; der Join-Bereich sagt stattdessen „Server-Details coming soon“. Diese Angaben können später in `index.html` ergänzt werden.
